## Task

M8's closeout (`docs/briefs/results/m8-asset-gap-dashboard-panel-result-v1.md` §0/§6/§7) found a
pre-existing (non-M8) defect: the live `public.get_client_production_readiness_queue` RPC returns
`scheduled_demand` as a **boolean**, but `invegent-dashboard`'s `lib/production-readiness-queue.ts`
types it `number | null` and parses it with a numeric parser, silently nulling every real value. This
has always broken the Production Readiness Queue tab's "Scheduled demand" display and structurally
prevented M8's own schedule-plan warning (`hasScheduledButNotExecutable`) from ever firing. Repair the
contract mismatch end to end: establish the authoritative backend meaning, correct the shared type and
parser, repair the existing display, make the Asset Gap schedule-plan flag work off the same
authoritative field, and add regression coverage.
